L'outil

Un observatoire de la commande publique, pensé pour les agents.

Focus Marchés s'adresse aux acheteurs et agents des collectivités. Il transforme des fichiers de données ouvertes, denses et techniques, en un outil d'exploration concret pour suivre, comparer et comprendre les marchés de son territoire.

Suivre l'activité d'achat

Visualisez le volume, le montant et la nature des marchés notifiés sur votre territoire, année après année.

Rechercher un marché ou un acheteur

Retrouvez un contrat, un profil d'acheteur public ou une entreprise titulaire en quelques filtres.

Comparer par territoire

Filtrez par département pour situer l'achat public local dans son contexte régional.

Les données

Les DECP, qu'est-ce que c'est ?

DECP

Les Données Essentielles de la Commande Publique sont les informations que tout acheteur public doit rendre publiques pour chaque marché conclu : objet, montant, durée, titulaire, lieu d'exécution.

Publiées en open data sur data.gouv.fr, elles sont normalisées mais difficiles à exploiter telles quelles. Focus Marchés les agrège, les nettoie et les rend explorables.

Open source

Libre, reproductible, déployable.

Focus Marchés est un logiciel libre sous licence CeCILL 2.1. Le code de l'API, des scripts d'import et de l'interface est public et installable par toute structure souhaitant ouvrir sa propre instance.

API + front, conteneurisés

Une API et des scripts d'import (Python), une interface Vue / TypeScript, le tout orchestré avec Docker Compose.

Import des données data.gouv

Synchronisation des DECP, des structures (API SIRENE) et des données financières (Infogreffe).

Configurable par région

Départements, sources, couleur de thème et mentions légales se paramètrent via un simple fichier .env.

Voir le dépôt Guide d'installation
~/focus-marches-v2
# 1 · Récupérer les sources
git clone https://github.com/collec-data/focus-marches-v2.git

# 2 · Configurer l'instance régionale
cp .env.default .env

# 3 · Lancer les conteneurs
docker compose build
docker compose up -d

# 4 · Importer les données ouvertes
docker compose exec api sh -c \
  "python app/importation.py decps --import-de-0"
